# Predictions before the same-model run
Written before any scored model answer on 2 October 2026.

I expect a strong model to do much better than the deliberately weak lexical baseline. It may solve all 48 raw logs. I do not predict an accuracy advantage for Context as a certainty.

I expect the same model to use the structured step record at least as reliably as the complete raw record. A receipt can still fail even if its status is right, especially when a generic success line does not identify the requested final check.

I expect explicit not shown answers when the final check is absent. The prompt makes that option clear in both arms. These results cannot be compared directly to the original benchmark's plain report prompt as if the prompts were identical.

Context should add retrievable structure, exact source links, and retained provider receipts. Those benefits need live checks, independently of the status count.

## Doubts considered and dismissed
- These predictions are preregistered. They are local development notes without an external seal.
- Any model error can be fixed for presentation. Retain the first answer and let the unchanged scorer count it.
